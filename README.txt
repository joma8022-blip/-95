БАРАКАТ — перенос сайта

1. Загрузите index.html и папку assets в корень своего сайта.
2. Добавьте рядом прежнюю папку img с фотографиями блюд. Названия файлов сохранены из старого сайта.
3. Если используете GitHub Pages, index.html должен лежать в корне выбранной для публикации папки.
4. Тексты, контакты, цены и блюда редактируются внутри index.html: откройте через Блокнот или VS Code.
5. Снимки assets — демонстрационные. При наличии img используются ваши фото блюд.
6. Исходный сайт работает независимо от ChatGPT.
